# gtaeditor
GTA Editor is an application (or game) made with Godot Engine for viewing the map of Grand Theft Auto: San Andreas.

### How to install

First, download the latest version of Godot Engine. Put it in bin/godot, then you need python and scons, clone godot-cpp repository, and run scripts/run.bat
